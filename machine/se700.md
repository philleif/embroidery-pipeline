# Brother SE700 quick reference

All limits below are from the operation manual (page numbers in parens).

## Hard limits

- **Hoop**: 4″ × 4″ = exactly 100 mm × 100 mm sewable area (p.96).
- **Max stitches per pattern**: 100 000 (p.96). `_print_pes_stats` warns above this.
- **Max embroidery speed**: 400 SPM (p.96). Typical operating average with
  trims/jumps is closer to 250 SPM — our run-time estimates use both bounds.
- **Internal memory**: 1024 KB total, ~20 patterns.
- **Accepted formats** (p.96): `.pes` (native, what we write), `.phc`, `.dst`,
  `.pen`. DST loses thread color info — machine substitutes a default sequence.
- **Single needle**: one color at a time. Auto-trim at color change is ON by
  default; within-color trims need explicit `inkstitch:trim_after="true"` in
  the source (tuning.py stamps this on every fill / satin / running path).

## USB

- FAT32 stick, PES files at root.
- Filename charset (p.96): `A–Z`, `a–z`, `0–9`, `-`, `_`. Anything else may not
  display. `batch_lettering` already sanitizes.
- Up to ~12 patterns visible at once on the touchscreen.
- The machine writes its own settings backups to a `bPocket/` subfolder when
  you tap "save settings" with a USB stick inserted — **don't put PES files
  there**; we write to the USB root.
- The machine can also mount over its USB-B cable as a removable disk;
  `stitch deploy --device /Volumes/<name>` works the same way.

## Wireless (informational — not used)

The SE700 has 2.4 GHz Wi-Fi (WPA/WPA2-Personal) and a "wireless function
pocket" that shows up on the touchscreen alongside USB and internal memory.
**Brother's transfer apps are Windows-only**: Design Database Transfer (free)
and PE-Design 11+ (paid). No macOS option. Patterns saved to the wireless
pocket are deleted on power-off unless promoted to internal memory. We use USB.

## Coordinate / placement convention

PES files for this machine want the design bbox anchored at `(0, 0)` extending
positive. The machine reads the bbox header and places the design centered in
the hoop. pyembroidery's internal stitch coordinates are 0.1 mm units; the
toolchain handles the conversion. `lettering.merge_pes_vertical()` enforces
this anchoring explicitly.

If a loaded design displays off-center on the touchscreen, use the **Move**
key. The 9-point reference grid (p.78) aligns the needle to any
corner/edge/center of the pattern — also the right tool for restarting after
a thread break.

## Thread metadata

Ink/Stitch outputs PES files with threads matched to the closest Brother
palette entry (so a Madeira 1023 black ends up labeled "Brother Black #20").
`convert.normalize_pes(preset=...)` overrides this — the PES gets the actual
brand and catalog number (e.g. "Madeira Classic Rayon 1023"). The machine
respects this when its on-screen *thread brand* setting is left at `Original`
(the default).

## Operator flow at the machine

1. Insert the USB stick.
2. Touchscreen → **USB icon**.
3. Select the design.
4. Hoop the fabric with the appropriate stabilizer (per the preset). Goal:
   drum-tight when tapped lightly.
5. Thread the listed needle (75/11 for general, 90/14 sharp for twill / dense
   fills). Confirm against the preset.
6. Optional: turn on **Embroidery Frame Identification View** in settings —
   designs that won't fit the attached frame are greyed out.
7. Press the green **Start** button.
8. Multi-color designs only — pause for thread change; swap to the next
   thread in `preset.threads` order, press **Start** again.
9. After all colors: hand-trim any visible jump threads inside color blocks.
   (Between-object trims are handled by PES TRIM commands the file carries.)

## Settings the touchscreen owns (not in the PES)

- Display units (mm / inch)
- Thread color display: name or `#123` number
- Thread brand display: `Original` (= file metadata) vs. specific brand
- Auto thread cut at color change (default ON)
- Embroidery Frame Identification View (default OFF)
- Embroidery speed (slider; max 400 SPM)

## Common gotchas

- Machine doesn't see the design → USB not FAT32, files in subfolders, or
  filename has disallowed characters.
- Stitching loose / loopy → top tension (dial 2–6; ~⅔ top / ⅓ bobbin on the back).
- Fabric showing through fills → stabilizer too light (two layers medium
  tear-away for twill) or hoop not snug.
- "Pattern extends to outside of embroidery frame" error → design exceeds
  100 mm in one dimension, or the wrong frame is selected.
- Design clipped / off-center on the touchscreen preview → file's bbox
  doesn't anchor at (0, 0). Operator can re-center via Move; we should
  also fix the file (`merge_pes_vertical` does this).
