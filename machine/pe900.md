# Brother PE900 quick reference

Embroidery-only machine (no sewing functions). All limits below come from the
operation manual's specification table unless noted.
Manual: https://download.brother.com/welcome/doch102511/888_k80_l80_l82_om01en.pdf

## Hard limits

- **Embroidery field**: maximum pattern size **180 mm × 130 mm**
  (7-3/32″ × 5-1/8″). The field is **not square** — 130 mm across the hoop,
  180 mm front-to-back. A design can clear one axis and bust the other, so
  `_print_pes_stats` checks both and says when a design would fit rotated 90°.
- **Max stitches per pattern**: 200 000.
- **Max embroidery speed**: 650 SPM. Real average with trims and colour
  changes is lower; run-time estimates use 400–650.
- **Memory**: 1024 KB total, or 20 embroidery patterns.
- **Accepted formats**: `.pes` (native, what we write), `.phc`, `.dst`, `.pen`.
  DST carries no thread-colour information, so the machine substitutes its
  default sequence and shows the design by filename with no thumbnail.
- **Single needle**: one colour at a time.

Turning on **Embroidery Frame Identification View** greys out any pattern that
won't fit the selected frame — worth leaving ON as a last-line check.

## Trimming — different from a plain lockstitch

The PE900 has two automatic trim features, both of which change how much hand
finishing a dense multi-object design needs:

- **Jump Stitch Trim** — automatically trims jump stitches as it sews, with a
  settings-screen control for the *minimum jump length not to trim*. Raising
  that threshold leaves short hops as travel stitches instead of cutting.
- **End Color Trim** — automatic thread cut at the end of each colour block.

This matters for traced wordmarks, which are built from hundreds of separate
satin columns. See the `data-trim-after` / `data-min-jump-mm` per-path controls
in `tuning.py`, and note that `force_lock_stitches` forces a TRIM after an
object no matter what `trim_after` says — the two are coupled.

## USB

- PES files at the **root** of the stick, no subdirectories.
- Filename charset (manual): `A–Z`, `a–z`, `0–9`, `-`, `_`. Anything else may
  not display. `batch_lettering` already sanitizes.
- The machine writes its own saves to a `bPocket/` folder — **don't put PES
  files there**; we write to the USB root.
- Some USB flash drives are not compatible; the manual is explicit that this is
  device-dependent. If a known-good file doesn't appear, try another stick
  before suspecting the file.

## Wireless

Wireless LAN is built in and, unlike the SE700, is a supported route: patterns
can be sent with Brother's Design Database Transfer / PE-DESIGN 11+. Both are
**Windows-only**, so on macOS we still use USB. Patterns parked in the wireless
function pocket are deleted at power-off unless promoted to memory.

## Coordinate / placement convention

PES files want the design bbox anchored at `(0, 0)` extending positive. The
machine reads the bbox header and centres the design in the hoop. pyembroidery's
internal stitch coordinates are 0.1 mm units; the toolchain handles the
conversion. `lettering.merge_pes_vertical()` enforces this anchoring explicitly.

If a loaded design displays off-centre, use the **Move** key; the reference grid
aligns the needle to any corner/edge/centre of the pattern, and is also the right
tool for restarting after a thread break. `stitch offset` does the same thing in
the file by extending the bbox with a phantom jump — now capped per axis at
`(130 − design_w) / 2` and `(180 − design_h) / 2`.

## Tension and jump-trim settings

**Upper tension** lives in two places. Settings screen → **[Embroidery Tension]**
is the global one and applies to every pattern — use it for overall bias. The
tension key on the embroidery screen fine-tunes a single pattern. The manual
publishes no "correct" number; it is judged on the fabric:

- Correct — upper thread *just* visible on the wrong side (bottom).
- Too tight — bobbin thread shows on the **right side (top)**. Decrease.
- Too loose — upper thread has slack. Increase.

The professional version of the same test: on the back of a satin column you
want bobbin thread as the **centre third**, upper thread either side of it.

**Bobbin.** Use the included 90 wt embroidery bobbin thread — the bobbin case
(no colour on the screw) is factory-set for exactly that weight. If a different
bobbin weight forces an adjustment, turn only the slotted (−) screw; **never
the phillips (+) screw**, which damages the case.

**Jump Stitch Trim** is ON from the factory. Its setting is *"Length of Jump
Stitch Not to Trim"* — you choose a length and the machine leaves any jump of
**that length or less** uncut (the manual's example: choose 25 mm and jumps of
25 mm or under survive). The setting persists across power cycles. It is
cancelled when the 2 × 6 cm small frame is selected.

Note what this does **not** do: it only governs jumps the file leaves untrimmed.
Our Ink/Stitch output writes an explicit TRIM at every jump — measured across
`paris-review-5in.pes` (82/82) and `makeout-summer-lockup-v4-satin.pes` (88/88),
there are zero bare jumps — so this setting changes nothing on our own files.
Trim count is controlled in the file (`data-trim-after` / `data-min-jump-mm`,
and the `force_lock_stitches` coupling). The machine setting matters for
outside files from digitizers who leave jumps in.

## Needles and thread

- Manual recommends a **75/11** home-machine needle as default, **90/14** for
  heavy fabric. That matches the presets in `materials/needles.toml`.
- The needle threader works with 75/11 through 90/14.
- Upper thread tension is adjusted **on the touchscreen** (touch the tension
  key; the number goes up to tighten). Correct when the upper thread is just
  visible on the underside.

## Operator flow

1. Insert the USB stick.
2. Touchscreen → **USB icon** → select the design.
3. Hoop the fabric with the appropriate stabilizer (per the preset). Goal:
   drum-tight when tapped lightly.
4. Thread the listed needle; confirm against the preset.
5. Press **Start**.
6. Multi-colour only — pause for thread change; swap to the next thread in
   `preset.threads` order, press **Start** again.
7. After all colours: cut any excess thread jumps remaining within a colour.

## Common gotchas

- Machine doesn't see the design → files in subfolders, disallowed characters
  in the filename, or an incompatible USB stick.
- "Pattern extends outside the embroidery frame" → design exceeds 130 mm across
  or 180 mm deep, **or the wrong frame is selected on the screen**.
- Design clipped / off-centre in the preview → the file's bbox doesn't anchor at
  (0, 0). Operator can re-centre via Move; we should also fix the file.
- Fabric showing through fills → stabilizer too light (two layers medium
  tear-away for twill) or hoop not snug.
